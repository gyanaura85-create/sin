
# NearKart 🛒
### Your Neighbourhood, Your Marketplace

NearKart is a local marketplace app that connects customers with nearby shops and sellers.

## Features
- Browse nearby shops and products
- Grocery, Fashion, Electronics, Food and more
- Add products to cart
- Place orders
- Seller registration and dashboard
- Order status tracking
- Push notifications
- English, Hindi and Odia language support
- Supabase backend integration

## Technology
- React Native
- Expo
- Supabase
- Expo Notifications

## App Name
NearKart

## Build
Android APK is built using Expo EAS Build.
